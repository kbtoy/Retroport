# wotlkconv (kept in retroport)

An unchanged copy of **wotlkconv**, the conversion engine and game-file readers (CASC, DB2, M2, BLP)
retroport is built on, from https://github.com/Bar3b0n3s/Converter - MIT License, (c) Converter contributors: see `LICENSE` here.

Copied from commit `a31b49f7d167baab5508ac65fde1be6bfecbd85f` (2026-10-29). retroport keeps its own copy so it installs, tests and builds
releases without depending on that repository staying online. To update it, clone the repository at
the commit you want and run `python packaging/update_wotlkconv.py <the clone>`.
